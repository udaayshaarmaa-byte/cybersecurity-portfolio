# Security Plans, Compliance & NIST CSF

---

## 1. Security is a Culture, Not a Department

- Security = a shared set of values across **all levels** of an organisation  employees, vendors, customers
- Protecting assets requires everyone to participate
- Security plans exist to prepare for risks when they happen and ensure everyone is aligned

### Common Risk Categories (causes):
- Damage, disclosure, or loss of information
- Physical damage or malfunction of a device
- Attacks (intentional)
- Human error (unintentional)

---

## 2. Three Elements of a Security Plan

| Element | Function | Example |
|---|---|---|
| **Policy** | Strategic  sets rules that reduce risk and protect information; defines scope, objectives, limitations | Acceptable Use Policy (AUP)  outlines how employees may access corporate systems |
| **Standards** | Tactical  references that inform how to set policies; create a performance benchmark | NIST SP 800-63B password standard: passwords must be ≥8 characters |
| **Procedures** | Operational  step-by-step instructions for specific security tasks | How to choose a secure password; how to reset a locked account |

**Acceptable Use Policy (AUP)** = outlines secure ways employees may access corporate systems; commonly signed by new hires.

Policies, standards, and procedures vary by organisation  they are tailored to each company's goals and risk profile.

---

## 3. Compliance

**Compliance** = the process of adhering to internal standards and external regulations.

**Why it matters:**
- Maintains trust, reputation, safety, and data integrity
- Avoids fines, penalties, and lawsuits
- Critical in regulated industries: health care, energy, finance

**Regulation** = rules set by a government or authority controlling how something must be done.

---

## 4. NIST Cybersecurity Framework (CSF)

**NIST CSF** = a voluntary framework of standards, guidelines, and best practices to manage cybersecurity risk.

- Originally released **2014** to protect US critical infrastructure
- Developed by NIST (National Institute of Standards and Technology)  unbiased scientific body
- Adapted for both public and private sector, including small businesses
- Flexible  can be applied to any industry

---

## 5. Three Components of the CSF

### Component 1  Core
A set of desired cybersecurity outcomes that help organisations customise their security plan.

**Six functions (as of February 2024  Govern was added):**

| Function | What it covers |
|---|---|
| **Identify** | Know your assets, risks, and environment |
| **Protect** | Implement safeguards to protect critical assets |
| **Detect** | Identify when a security event occurs |
| **Respond** | Take action after a detected incident |
| **Recover** | Restore capabilities after an incident |
| **Govern** | Leadership and decision-making for managing cybersecurity risk (added 2024) |


### Component 2  Tiers
Measure the sophistication of an organisation's cybersecurity program.

| Tier | Label | Meaning |
|---|---|---|
| **1** | Passive | Bare minimum security controls implemented |
| **2** | Risk-Informed | Some risk awareness, but inconsistent practices |
| **3** | Repeatable | Formal policies in place, consistently applied |
| **4** | Adaptive | Exemplary standard; continuously improving based on threats |

Tiers show what is and isn't working  they're a range, not a binary pass/fail.

### Component 3  Profiles
Pre-made templates tailored to specific industries or organisations.

- Used to establish a **baseline** for a cybersecurity plan
- Used to **compare current posture** to an industry standard
- Like a photo capturing the current state  compare over time to see progress

---

## 6. Implementing the CSF (CISA Guidance)

1. Create a **current profile**  document existing security operations and business needs
2. Perform a **risk assessment**  identify which operations meet business and regulatory standards
3. **Analyse and prioritise gaps**  what's missing that puts assets at risk?
4. **Implement a plan of action**  achieve identified goals and objectives

**Pro tip:** always consider current risk, threat, and vulnerability trends when applying the CSF.

## Key Terms

| Term | Definition |
|---|---|
| Policy | Set of rules that reduce risk and protect information (strategic) |
| Standard | Reference that informs how to set policies; creates performance benchmark |
| Procedure | Step-by-step instructions for a specific security task |
| AUP | Acceptable Use Policy — defines how employees may use corporate systems |
| Compliance | Adhering to internal standards and external regulations |
| Regulation | Government/authority rules that must be followed |
| Framework | Voluntary resource organisations choose to use |
| NIST | National Institute of Standards and Technology |
| NIST CSF | Voluntary cybersecurity framework: standards, guidelines, best practices |
| CSF Core | Six functions: Identify, Protect, Detect, Respond, Recover, Govern |
| CSF Tiers | 1–4 scale measuring cybersecurity program sophistication |
| CSF Profiles | Industry/org-specific templates for establishing or comparing security posture |
